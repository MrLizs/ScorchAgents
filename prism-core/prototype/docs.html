🚀 快速开始

PrismCore 提供统一的 API 接口，让您能够快速集成多种主流 AI 模型。按照以下步骤，5 分钟内即可完成接入。

💡 开始之前，请确保您已在 API Key 管理 页面创建了密钥。

第一步：获取 API Key

1

登录控制台

进入 PrismCore 控制台，在「我的」页面找到「API Key 管理」

2

创建密钥

点击「创建 Key」，为您的应用（如生产环境、开发环境）命名并生成密钥

3

保存密钥

复制生成的密钥并安全保存。出于安全考虑，关闭后无法再次查看完整密钥

第二步：调用 API

PrismCore 提供兼容 OpenAI 格式的 API 接口，您可以使用任何 OpenAI SDK 直接接入，或使用以下示例代码。

cURL 示例

bash
curl https://api.prismcore.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-pc-xxxxxxxxxxxx" \
  -d '{
    "model": "gpt-4o",
    "messages": [
      {"role": "system", "content": "你是一个有用的助手。"},
      {"role": "user", "content": "你好，请介绍一下你自己。"}
    ],
    "temperature": 0.7,
    "max_tokens": 1024
  }'

Python 示例

python
from openai import OpenAI

client = OpenAI(
    api_key="sk-pc-xxxxxxxxxxxx",
    base_url="https://api.prismcore.ai/v1"
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "你是一个有用的助手。"},
        {"role": "user", "content": "你好，请介绍一下你自己。"}
    ],
    temperature=0.7,
    max_tokens=1024
)

print(response.choices[0].message.content)

JavaScript / Node.js 示例

javascript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-pc-xxxxxxxxxxxx',
  baseURL: 'https://api.prismcore.ai/v1',
});

async function main() {
  const response = await client.chat.completions.create({
    model: 'gpt-4o',
    messages: [
      { role: 'system', content: '你是一个有用的助手。' },
      { role: 'user', content: '你好，请介绍一下你自己。' },
    ],
    temperature: 0.7,
    max_tokens: 1024,
  });

  console.log(response.choices[0].message.content);
}

main();

📖 API 参考

PrismCore API 兼容 OpenAI 接口格式，支持 Chat Completions、Embeddings、Image Generation 等主流能力。

基础信息

  • Base URL: https://api.prismcore.ai/v1
  • 认证方式: Bearer Token（在 Header 中传递 API Key）
  • 请求格式: application/json

Chat Completions

bash
POST /v1/chat/completions

{
  "model": "string",           // 模型名称
  "messages": [
    {"role": "system", "content": "..."},
    {"role": "user", "content": "..."}
  ],
  "temperature": 0.7,          // 可选，默认 0.7
  "max_tokens": 1024,          // 可选，默认 4096
  "top_p": 1,                  // 可选，默认 1
  "stream": false               // 可选，默认 false
}

Embeddings

bash
POST /v1/embeddings

{
  "model": "text-embedding-3",
  "input": "要生成向量的文本内容"
}

可用模型列表

  • gpt-4o — OpenAI GPT-4o（多模态）
  • claude-3.5-sonnet — Anthropic Claude 3.5 Sonnet
  • gemini-1.5-pro — Google Gemini 1.5 Pro
  • qwen2-72b — 通义千问 Qwen2 72B
  • llama-3.1-405b — Meta Llama 3.1 405B
  • deepseek-v2 — DeepSeek V2
  • text-embedding-3 — OpenAI Embedding 模型
📘 完整的 API 文档请访问 api.prismcore.ai/docs。

📦 SDK 指南

PrismCore 提供官方 SDK 和服务端 SDK，方便不同语言环境下的快速集成。

Python SDK

使用 OpenAI Python SDK 即可接入 PrismCore（兼容 OpenAI API 格式）。

bash
pip install openai

Node.js SDK

bash
npm install openai

Go SDK

go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    url := "https://api.prismcore.ai/v1/chat/completions"
    payload := map[string]interface{}{
        "model": "gpt-4o",
        "messages": []map[string]string{
            {"role": "user", "content": "你好"},
        },
    }
    jsonData, _ := json.Marshal(payload)
    req, _ := http.NewRequest("POST", url, bytes.NewBuffer(jsonData))
    req.Header.Set("Authorization", "Bearer sk-pc-xxxxxxxxxxxx")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()
    fmt.Println("Status:", resp.Status)
}

Java SDK

xml
<dependency>

</dependency>

❓ 常见问题

Q: PrismCore 与 OpenAI 的接口兼容吗？

A: 是的，PrismCore API 完全兼容 OpenAI 接口格式，您可以直接使用现有的 OpenAI SDK 接入，只需修改 baseURL 和 API Key 即可。

Q: 如何查看 API 调用次数和费用？

A: 登录控制台后，在「统计」页面可以查看详细的调用记录、Token 消耗和费用明细。数据实时更新。

Q: 余额不足时 API 调用会怎样？

A: 当账户余额低于 ¥5 时，系统会发送余额提醒。余额耗尽后 API 调用将返回 402 Payment Required 错误，充值后自动恢复。

Q: API Key 泄露了怎么办？

A: 请立即在「API Key 管理」页面禁用或删除泄露的密钥，并创建新的密钥。建议定期轮换密钥以提高安全性。

Q: 支持模型微调 (Fine-tuning) 吗？

A: 目前 PrismCore 暂不支持模型微调功能。我们专注于提供高质量的推理 API 服务，微调功能已在规划中。

Q: 充值后多久到账？

A: 在线充值通常即时到账。如遇支付平台延迟，最迟 5 分钟内到账。若超时未到账，请联系客服处理。
