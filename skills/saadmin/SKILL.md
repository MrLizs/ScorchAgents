# saadmin — 后台管理面板

## 目标

从接口规范里挑出管理端接口（Admin 相关），据此生成一套能跑的后台：仪表盘、用户管理、数据管理、系统配置、操作日志等页面，带登录和权限控制。

## 输入

- 必需：`api/openapi.yaml`（含 Admin 接口）。
- 可选：`STEPS.md`（项目名、UI 风格、技术栈）。

## 产出

- `admin/`：可运行的后台工程（页面组件、路由、API 客户端、状态管理）。
- `admin/README.md`：启动说明。
- `STEPS.md`：追加"后台管理"节，记录页面清单和技术栈。

## 硬性底线

- 页面结构从 Admin 接口推导，接口有什么能力就做什么页面，不要凭空造没有后端支撑的功能。
- 后台接口走独立的认证（Admin JWT），和普通用户端分开。
- `STEPS.md` 里记下后台用到的框架和认证方式，`saapi-connect` 要据此接通。

## 交接

- 下游是 `saapi-connect`（把后台也接到真实 API），再往后是部署类卡。

## 自由发挥

- **框架、UI 库、状态管理、表格/表单方案**：自己判断或和用户商量，原卡的固定技术栈已删除。
- **页面划分、布局、导航、配色**：按项目需要定，不必套预设页面清单。
- **权限模型、菜单生成方式**：自己设计。
