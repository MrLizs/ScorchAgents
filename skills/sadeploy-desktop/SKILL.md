# sadeploy-desktop — 桌面应用打包

## 目标

根据 `desktop/` 用的框架，生成能出三大桌面系统安装包的构建脚本，说明每个平台需要的环境。

## 输入

- 必需：`desktop/`（由 `sadesktop` 产出）。
- 可选：`STEPS.md`（框架和打包配置）。

## 产出

- `desktop/build.sh`（或对应脚本）：构建脚本。
- `STEPS.md`：追加"桌面端打包"节，记录产物清单和状态。

## 硬性底线

- 脚本要覆盖目标平台，并说明跨平台限制——比如在 Linux 上打 Windows 包可能需要额外工具，别给出跑不通的方案。
- 签名证书、密钥等敏感信息不写死，用环境变量或占位符。

## 交接

- 这是桌面端链路的终点。上游是 `sadesktop`。

## 自由发挥

- **打哪些平台的包、输出什么格式、用什么脚本**：按用户需要定，原卡固定模板已删除。
- **版本号、图标、安装路径、签名方式**：按项目决定。
