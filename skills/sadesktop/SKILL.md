# sadesktop — Web 转桌面应用

## 目标

给 Web 前端套一层桌面壳，提供原生窗口、系统托盘、菜单、安全存储、自动更新、本地文件访问等能力，产出能在三大桌面系统跑的工程。

## 输入

- 必需：`frontend/`（前端代码，构建产物作为壳层内容）。
- 可选：`api/openapi.yaml`、`STEPS.md`。

## 产出

- `desktop/`：桌面工程（壳层主进程、预加载脚本、窗口配置、图标、打包配置、更新逻辑）。
- `STEPS.md`：追加"桌面应用"节，记录框架和打包配置。

## 硬性底线

- **Web 前端作为内容渲染，桌面壳只提供原生能力**——不要把页面逻辑在壳里重写一遍。
- **Token 存系统安全存储**（加密），不要写进普通配置文件。
- **预加载脚本安全暴露 API** 给渲染进程，不要把原生能力 wholesale 挂到全局。
- 代码放 `desktop/`，与其他工程平级。

## 交接

- 下游是 `sadeploy-desktop`（打包 .exe / .dmg / .deb / .AppImage）；需要托盘、文件对话框等能力时可叠 `sanative-bridge`。

## 自由发挥

- **壳层框架**（Electron / Tauri 等）、**是否把后端打进应用**（单机模式 vs 连远程服务器）：按项目需要定。
- **窗口行为、菜单、托盘、更新策略**：自己设计。
- **打包格式、图标、签名**：按目标平台和所选框架决定。
